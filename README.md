# PriceIQ – AI-Powered Price Intelligence Platform

An intelligent price valuation platform that combines Machine Learning, similarity search, and Generative AI to predict fair market prices, identify comparable listings, and generate explainable pricing insights.

## Overview

PriceIQ aims to transform marketplace pricing data into actionable intelligence. Using real-world listing data, the platform will estimate item valuations, retrieve similar listings, and explain the factors influencing predicted prices.

The project brings together classical Machine Learning and modern Generative AI techniques in a unified valuation system.

## Key Features

- **Price Prediction:** Estimate fair market prices using regression algorithms.
- **Comparable Listings:** Identify similar marketplace listings using K-Nearest Neighbors (KNN).
- **Explainable AI:** Understand pricing drivers using SHAP.
- **Semantic Search:** Explore embedding-based similarity search using FAISS.
- **AI-Powered Insights:** Generate natural-language valuation explanations using RAG.
- **Interactive Application:** Explore predictions and market insights through a Streamlit interface.
